# GitHub Practice
* Purpose: The purpose of the repository is like a storage of your files in your project like the codes anything related to your project
* Git and Github: Git and Github are version control systems that allows developers to keep track on the changes in their codes. Github's primary purpose is to make developer work on the same project from anywhere, while Git can also keep track on the code but also locally in your own pc without having an internet.
* Commit: Commit is like saving your project at the certain point like taking a snapshot and record your work.
